# VideoAgent 项目指令

## 通用规则

1. 所有回复必须用中文
2. 输出文件写到项目工作空间 `D:\AI\Projects\aiVideoAgent\`
3. 开始前如有不清楚的地方务必先询问用户具体需求，不要直接运行脚本
4. 虚拟环境是conda的ai-video

## 变更记录要求

**每次对项目的代码或文档进行修改后，必须在 `logs/CHANGELOG.md` 文件末尾追加变更记录。**

格式：
```markdown
## YYYY-MM-DD

### 简短标题
- **新增** `文件路径`：描述
- **更新** `文件路径`：描述
- **修复** `文件路径`：描述
- **删除** `文件路径`：描述
```

规则：
- 每次修改后追加到最新日期条目下
- 如果当天已有条目，追加到该日期下方
- 如果当天没有条目，新建日期条目
- 变更标题用一句话概括本次修改的核心内容
- 使用 `新增` / `更新` / `修复` / `删除` 分类标记
- 文件路径使用相对路径（相对于项目根目录）
