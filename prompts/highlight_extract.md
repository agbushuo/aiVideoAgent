基于以下视频字幕，请完成两个任务：

## 任务 1: 视频总结
用 2-3 句话概括视频的核心内容，包括主题、主要观点和结论。

## 任务 2: 亮点提取
选出 3-8 个最值得保留的精彩片段。

每个亮点必须包含：
- `segment_id`: 对应字幕片段的序号 (从 0 开始，参考字幕中的 #N 标记)
- `start` / `end`: 时间戳 (秒，从字幕的时间标记中提取)
- `title`: 亮点标题 (简短有力，8-15 字)
- `reason`: 为什么值得保留 (具体说明，20-50 字)
- `score`: 重要度评分 (0.0-1.0，越高越重要)

## 评分标准
- **信息密度**: 内容是否信息量大、不注水
- **观点价值**: 是否有独到见解或重要观点
- **实用性**: 对观众是否有实际帮助

## 输出格式
严格 JSON，不要 markdown 代码块标记：

{{
  "summary": "视频总结...",
  "highlights": [
    {{
      "segment_id": 0,
      "start": 10.5,
      "end": 45.2,
      "title": "亮点标题",
      "reason": "原因说明",
      "score": 0.95
    }}
  ]
}}
